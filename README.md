# MultiChoice Medical

تطبيق Android عربي (RTL) للتدرب على أسئلة الاختيار من متعدد الطبية، مبني باستخدام Kotlin وJetpack Compose وRoom.

## الوظائف الموجودة في المستودع
- واجهة عربية تدعم اتجاه RTL.
- بنك أسئلة محلي يعمل دون اتصال بعد التحميل الأول.
- تصنيف الأسئلة حسب التخصص/الفئة.
- إنشاء اختبار بعدد أسئلة يحدده المستخدم مع ترتيب عشوائي للأسئلة.
- مؤقت اختياري (15 أو 30 أو 60 دقيقة) وإنهاء تلقائي عند انتهاء الوقت.
- اختيار الإجابة، إظهار الإجابة الصحيحة والتفسير، واحتساب النتيجة.
- حفظ سجل الاختبارات محلياً في Room مع ترحيل قاعدة البيانات من الإصدار 1 إلى 2.
- مزامنة تنزيلية اختيارية من Supabase REST.
- GitHub Actions لبناء APK تجريبي عند كل push إلى main.

## البناء
المتطلبات: Android Studio حديث، JDK 17، Android SDK 35، Gradle 8.9.

```bash
gradle assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

يمكن تنزيل artifact باسم `MultiChoiceMedical-debug-apk` من تبويب Actions بعد اكتمال سير العمل بنجاح. هذا APK مخصص للتجربة وموقّع بمفتاح debug، وليس إصداراً نهائياً للنشر على Google Play.

## إعداد Supabase
1. أنشئ مشروعاً في Supabase.
2. نفّذ `supabase/schema.sql` من SQL Editor.
3. نفّذ `supabase/seed.sql` لإضافة الأسئلة التجريبية.
4. في GitHub افتح Settings ثم Secrets and variables ثم Actions وأضف:
   - `SUPABASE_URL`: رابط مشروع Supabase.
   - `SUPABASE_ANON_KEY`: مفتاح anon/publishable الخاص بالمشروع.
5. ادفع commit جديداً أو أعد تشغيل GitHub Actions.

لا تضع مفتاح `service_role` في التطبيق أو في مستودع Git. المفتاح العام anon لا يغني عن ضبط سياسات RLS بشكل صحيح.

## حدود النسخة الحالية
- مزامنة Supabase تنزيلية فقط؛ لا توجد بعد واجهة إدارة سحابية أو رفع/تعديل للأسئلة من التطبيق.
- الوصول في ملف SQL التجريبي عام للقراءة؛ لذلك لا تستخدمه مع بنك أسئلة سري أو امتحانات حقيقية تحتوي على مفاتيح إجابة يجب حمايتها.
- لا يوجد حتى الآن تسجيل دخول للمستخدمين أو مزامنة سجل النتائج بين الأجهزة.
- بنك الأسئلة المرفق أربعة أسئلة تجريبية فقط، ولا يمثل بنكاً كافياً لأي امتحان تخصصي.
- إصدار Google Play يتطلب إعداد توقيع Release آمن وإكمال متطلبات النشر والخصوصية.

## السلامة الطبية
الأسئلة المرفقة لأغراض اختبار التطبيق تقنياً فقط. لا تعتمد عليها لاتخاذ قرار سريري أو للتحضير الرسمي قبل مراجعة كل سؤال وإجابته وتفسيره من مصادر حديثة ومراجع معتمدة بواسطة مختصين.
