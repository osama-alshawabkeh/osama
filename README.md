# MultiChoice Medical

منصة تعليم طبي تجارية قيد التطوير، تتكون من تطبيقين منفصلين لنظام Android يشتركان في Backend واحد.

## التطبيقات

| التطبيق | Package ID | الوظيفة |
|---|---|---|
| MultiChoice Medical | com.multichoice.medical | تطبيق الطالب والتدريب والاختبارات |
| MultiChoice Admin | com.multichoice.admin | تطبيق إدارة المحتوى والمستخدمين والمنصة |

## الحالة الحالية

- تطبيق الطالب الحالي محفوظ مع Package ID الأصلي لتجنب كسر التحديثات.
- تمت إضافة وحدة Android مستقلة لتطبيق الإدارة مع واجهة RTL أولية وتبويبات رئيسية.
- تمت إضافة وثيقة المعمارية وخطة المراحل.
- تمت إضافة أساس مخطط قاعدة البيانات التجارية في supabase/migrations.
- تم تحديث GitHub Actions لبناء APK منفصل لكل تطبيق.
- واجهة الإدارة الحالية تأسيسية فقط؛ الأرقام وعمليات الإدارة لن تعمل فعلياً قبل ربط المصادقة والخدمات الخلفية.
- لا تعتبر المنصة جاهزة للإنتاج أو تحصيل الاشتراكات بعد.

## بناء التطبيقات

المتطلبات: JDK 17 وAndroid SDK 35 وGradle 8.9.

```bash
gradle --no-daemon :app:assembleDebug
gradle --no-daemon :adminApp:assembleDebug
```

GitHub Actions ينشر artifact باسم:
- MultiChoiceMedical-client-debug-apk
- MultiChoiceAdmin-debug-apk

هذه نسخ Debug للاختبار، وليست نسخ Release موقعة للنشر في Google Play.

## إعداد Supabase

1. أنشئ مشروع Supabase منفصلاً لبيئة التطوير.
2. راجع migration في supabase/migrations/202611110001_commercial_core.sql قبل تطبيقه.
3. طبّق migration على قاعدة بيانات اختبار أولاً.
4. اختبر RLS بأدوار طالب ومحرر محتوى ومدير، وتأكد من عدم قدرة الطالب على قراءة مفاتيح الإجابة.
5. لا تضع service_role key داخل APK أو في مستودع Git.
6. اربط التطبيقات بمصادقة Supabase وخدمات Edge Functions بعد إعداد مفاتيح البيئة الآمنة.

## المعمارية وخطة التنفيذ

راجع docs/ARCHITECTURE.md للتفاصيل، بما يشمل:
- وحدات تطبيق العميل والإدارة.
- المصادقة والأدوار وصلاحيات RLS.
- إدارة الأسئلة والاختبارات.
- حماية مفاتيح الإجابات والتصحيح من جهة الخادم.
- الاشتراكات والدفع والإشعارات.
- مراحل الاختبار والإطلاق.

## السلامة الطبية

المحتوى التجريبي الموجود في النسخة الحالية لا يمثل بنك أسئلة طبياً مكتملاً أو معتمداً. يجب مراجعة كل سؤال وإجابة وشرح ومصدر بواسطة مختصين وبالرجوع إلى مراجع طبية حديثة قبل استخدامه للتحضير الرسمي أو اتخاذ قرار سريري.
